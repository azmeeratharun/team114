# StudyMate: AI-Powered PDF-Based Q&A System for Students

## Overview
StudyMate allows students to upload PDFs and interact with them by asking questions. The system extracts text, embeds it, performs semantic search, and generates grounded answers using an LLM.

## Setup
1. Create and activate a virtual environment.
2. Install dependencies:
    bash
    pip install -r requirements.txt
    
3. Run the Streamlit app:
    bash
    streamlit run app.py
    

## Features
- PDF upload
- Semantic search
- LLM answer generation
